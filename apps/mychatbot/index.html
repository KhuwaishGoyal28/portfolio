MyChatbot

Chat UI with text-to-speech and a GIF generator.

Demo reply mode. The original app sends messages to Google Gemini (gemini-1.5-flash) from a Flask server. This static web version has no server and no API key, so bot replies are pre-written demo messages, not AI output. To get real Gemini replies, run the Python app with your own key (see the README).

AI image generator

The original generates images with Stable Diffusion v1.5 (diffusers) on your own GPU or CPU. A multi-gigabyte diffusion model can't run on this static page, so image generation is only available in the Python app.

GIF generator

The original makes a Stable Diffusion image, then turns it into an 8-frame zoom-and-rotate GIF. Here you provide the image yourself; the GIF effect (make_gif: 8 frames, rotate 3° per frame, scale +7%, 200 ms) runs in your browser.
