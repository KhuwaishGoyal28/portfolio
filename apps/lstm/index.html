About this model

Architecture from the notebook: LSTM(50, return_sequences=True) → LSTM(50) → Dense(1), Adam, MSE loss, 20 epochs, batch size 16, trained on ADANIPORTS.csv (NSE daily data, 2007–2021). The notebook also explored seasonal decomposition and a Prophet baseline.

The notebook does not save a trained model file, so the weights used here come from re-running the notebook's exact training code (seed 42). Its test MSE is close to the notebook's reported 825.43, but not identical. The LSTM forward pass is written in plain JavaScript and matches Keras to within ₹0.001.
